 NOTE :
 GOT refers to the Global Offset Table, a memory section storing addresses 
 of dynamically linked functions.  A GOT entry is a specific location within 
 this table that holds the runtime address of a function or variable, often 
 targeted in security exploits like Return Oriented Programming (ROP) because 
 the GOT is writable.
